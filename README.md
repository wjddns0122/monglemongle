# 몽글몽글 수선점 (Monglemongle Repair Shop)

A cozy toy-repair game made with Unity: find what hurts the plush friends, mend them with the right tool, and let them move into the village.

## Open the project

- Unity **6000.6.3f1** (Universal Render Pipeline)
- Open this folder in Unity Hub, then open `Assets/_Project/Scenes/Bootstrap.unity` and press Play.

## Layout

- `Assets/_Project/Scenes` — Bootstrap (start screen), RepairShop, PhotoStudio, Village
- `Assets/_Project/Scripts` — game code (Core, Repair, Village, Photo, UI) and editor tools
- `Assets/_Project/Resources/UI` — UI pictures and the Cafe24 Ssurround font
- `Assets/_Project/Prefabs/UI/TitleScreen.prefab` — the start screen, editable in the scene
